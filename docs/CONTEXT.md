# 当前进度与版本边界

## 2026-11-19 · 发布第 7～23 课

课程源码与模型位于四个 ROS 包，按[学习目录](learning/README.md)区分板端只读与电脑端仿真。第 13～14 课曾在作者的 RK Jazzy → WSL Humble 链路获得六轴反馈并显示四轴标称模型。第 15～23 课使用 WSL 模拟关节状态与轨迹 Action。

同一段 140 mm 模型横移在 28 mm/s 时用时 5.5 s。根据 WSL 模型反馈，梯形速度的加速度极值为 +56.018 / −56.015 mm/s²，三次平滑起停为 +83.862 / −83.811 mm/s²。[速度和加速度图与复现命令](learning/CPP_LESSON23_ACCELERATION.md)

## 2026-11-17：当前学习成为仓库主线

- 当前入口为native和两个C++ROS包，六节中文课程集中在docs/learning。
- 作者在RK3568上完成C++六轴查询，随后在同一RK的两个SSH窗口完成rclcpp发布/订阅。示例消息sequence=39、有效6/6、43.063ms，P为1511/1505/1492/1497/1503/1480；仅记录非敏感摘要，不公开原始日志或现场配置。
- WSL Humble开发者测试与RK Jazzy作者实测分别报告；同一RK两个终端不等于PC↔RK DDS已打通。
- 原始P不是弧度，当前自定义消息不直接用于JointState或空间精度验收。下一课按计划学习PC WSL Service。
- 旧Python ROS节点、标称模型、静态视觉节点和ESP32代码归入legacy。Python业务基线仍在src/arm_project以保留导入兼容；其合成夹具与跨平台修复保留。
- Python旧运动基线沿用此前公开版本；本次没有把作者未公开的后续运动改动、现场阈值或校准配置混入当前课程。

本次本地公开验收通过：822项Python测试（Windows下5项平台/链接权限跳过）、Ruff/格式/依赖、默认dry-run与文档链接；另通过3项C边界、22项C++PTY及4项Humble ROS＋PTY检查。公开源码可自行生成22文件学习包，不依赖作者私有压缩包。
